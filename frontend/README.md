# Interview Agent - Frontend

The React-based user interface for the AI Interview Coach application. This frontend connects to the FastAPI backend to provide real-time voice interviews, resume analysis, and coding tests.

## Tech Stack
- **React 18**
- **Vite** (Build tool)
- **TailwindCSS** (Styling)
- **Zustand** (State Management)
- **React Router** (Navigation)

## Getting Started

1.  Iinstall dependencies:
    ```bash
    npm install
    ```

2.  Start the development server:
    ```bash
    npm run dev
    ```

3.  Build for production:
    ```bash
    npm run build
    ```

## Key Features
- **Dashboard**: Track interview progress and stats.
- **Interview Room**: Real-time voice interaction.
- **Coding Test**: Integrated code editor for technical questions.
- **Resume Analysis**: Upload and analyze resumes.
